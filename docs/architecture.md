# Архітектура проекту «Піратський ресторан» (C4)

## C4 Level 1 — System Context

### Основні учасники
- **Гість ресторану** — користувавач у браузері, який переглядає меню, робить замовлення та бронює столик.
- **Адміністратор ресторану** — користувач адмінки Django для керування меню та бронюваннями.

### Основна система
- **Pirate Restaurant System** — веб-застосунок на Django, який надає:
  - сайт для перегляду меню та бронювання
  - REST API для роботи зі стравами та бронюваннями
  - адмінку для керування даними

### Зовнішні системи
- **PostgreSQL Database** — зберігає дані про меню, бронювання, користувачів.
- **Docker Compose** — orchestrator контейнерів для запуску бекенду та бази даних.

### Опис контексту
- Гість використовує браузер для доступу до сайту.
- Django обробляє HTTP-запити та надає HTML-сторінки й API.
- PostgreSQL зберігає дані, а Docker Compose запускає середовище.

## C4 Level 2 — Container Diagram

### Контейнери
- **Backend (Django)**
  - Розташування: `backend/`
  - Відповідає за бізнес-логіку, маршрути, шаблони, API, автентифікацію та міграції.
  - Взаємодіє з PostgreSQL через змінну `DATABASE_URL`.

- **DB (PostgreSQL)**
  - Розташування: контейнер `db` у `docker-compose.yml`
  - Зберігає `MenuItem`, `Reservation`, а також дані користувачів Django.
  - Підключено volume `postgres_data` для стійкого зберігання.

- **Docker Compose**
  - Описує сервіси `web` і `db`.
  - Забезпечує `depends_on`, товариство між контейнерами та монтування коду з хосту.

### Архітектурна взаємодія
1. **Користувач** відкриває браузер і звертається до `http://localhost:8000`.
2. **Docker Compose** запускає контейнер `web`, що будує образ з `backend/Dockerfile`.
3. **Django** обробляє запит і читає налаштування з `.env` / `DATABASE_URL`.
4. **PostgreSQL** контейнер відповідає за збереження і читання даних.
5. **Volume** `postgres_data` гарантує, що після перезапуску дані не втрачаються.

### Примітка про фронтенд
- У цьому проекті фронтенд реалізовано як серверно-згенеровані HTML-шаблони Django.
- За потреби можна додати окремий фронтенд-контейнер у майбутньому.
